# Algeria’s Memories and Colors — ذاكرة وألوان الجزائر

بوابة رقمية تفاعلية مخصصة لحفظ وتوثيق الذاكرة الوطنية الجزائرية، صور ووثائق الشهداء والمفقودين والشخصيات التاريخية إبان الحقبة الاستعمارية.

---

## 📌 محتويات المشروع

- **البوابة الرئيسية (`index.html`)**: واجهة ترحيبية حديثة وأنيقة تتيح تصفح أقسام الأرشيف والبحث العام وإحصائيات المحتوى.
- **أرشيف الصور (`photos.html`)**:
  - عرض وتصفح مئات الصور الموثقة بدقة.
  - بحث فوري بالاسم (بالأحرف اللاتينية أو العربية) مع فلترة ديناميكية.
  - عارض متقدم للصور مع إمكانية التحميل والتدوير والتكبير.
  - نظام تسجيل الشهادات والرسائل العائلية لكل شخصية مع رمز أمان (Captcha) ونظام مراجعة.
- **أرشيف الوثائق التاريخية (`documents.html`)**:
  - استعراض الوثائق والمراسلات والأرشيف الورقي التاريخي.
  - ربط الوثائق بالشخصيات المرتبطة بها في أرشيف الصور.
- **قواعد البيانات المحلية (`.js`)**:
  - `photos_data.js`: قاعدة بيانات سجلات الصور.
  - `documents_data.js`: سجلات الوثائق التاريخية.
  - `comments_data.js`: الشهادات والرسائل المعتمدة.

---

## 🛡️ الخصوصية والأمان

تم ضبط إعدادات المشروع لتأمين الإدارة والبيانات الحساسة:
- استبعاد بوابة الإدارة المحلية (`admin.html`) ومجلد السكربتات الداخلية (`_scripts_archive/`) تلقائياً عبر ملف `.gitignore`.
- إضافة ملف `robots.txt` لمنع محركات البحث من أرشفة صفحات الإدارة الداخلية.
